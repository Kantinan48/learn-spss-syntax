# 📊 Learn SPSS Syntax

คลังเก็บซอร์สโค้ด **SPSS Syntax** และบันทึกการเรียนรู้สำหรับรายวิชา **ระเบียบวิธีวิจัยด้านคอมพิวเตอร์ (Computer Research Methodology)** จัดทำขึ้นเพื่อรวบรวมคำสั่งการจัดการข้อมูล การเขียนสคริปต์วิเคราะห์ผลทางสถิติ และแบ่งปันโค้ดให้เพื่อนในกลุ่มสามารถนำไปรันซ้ำ (Reproducible) ได้อย่างรวดเร็วและถูกต้อง

## 🎯 วัตถุประสงค์ของโปรเจกต์
* **รวบรวมคำสั่ง Syntax:** เก็บสคริปต์ตั้งแต่การสร้างโครงสร้างตัวแปร การนำเข้าข้อมูล ไปจนถึงการวิเคราะห์ทางสถิติในแต่ละสัปดาห์
* **ลดข้อผิดพลาดในการทำงานซ้ำ:** สามารถรันโค้ดเพื่อสร้างชุดข้อมูลตั้งต้นได้ใหม่ภายในคลิกเดียว โดยไม่ต้องเสียเวลาตั้งค่าในหน้า Variable View หรือกรอกข้อมูลใหม่ทีละช่อง
* **แบ่งปันและทำงานร่วมกัน:** ใช้เป็นแหล่งอ้างอิงกลางสำหรับเพื่อนร่วมคลาสในการคัดลอกโค้ดหรือดาวน์โหลดไฟล์ไปศึกษาต่อ

## 📋 ภาพรวมชุดข้อมูลตั้งต้น (Dataset Overview)
ข้อมูลตัวอย่างในโปรเจกต์นี้ประกอบด้วยกลุ่มตัวอย่างจำนวน **40 รายการ ($N = 40$)** และตัวแปรทั้งหมด **6 ตัวแปร** ดังนี้:

| ตัวแปร (Name) | ประเภทข้อมูล | ระดับการวัด (Measure) | รายละเอียดค่าข้อมูล (Values) |
| :--- | :---: | :---: | :--- |
| `gender` | Numeric | Nominal | `1` = male, `2` = female (Missing: `9`) |
| `age` | Numeric | Scale | อายุ (ปี) |
| `status` | Numeric | Nominal | `0` = Normal, `1` = Night (Missing: `9`) |
| `gradePrg1` | Numeric | Ordinal | เกรดวิชา Programming 1 (`4`=A, `3`=B, `2`=C, `1`=D, `0`=F) |
| `gradePrg2` | Numeric | Ordinal | เกรดวิชา Programming 2 (`4`=A, `3`=B, `2`=C, `1`=D, `0`=F) |
| `GPA` | Numeric | Scale | เกรดเฉลี่ยสะสม (ทศนิยม 2 ตำแหน่ง) |

## 🚀 วิธีนำโค้ดไปรันในโปรแกรม IBM SPSS

1. **เปิดไฟล์คำสั่ง:** เปิดโปรแกรม **IBM SPSS Statistics** ไปที่เมนู **File > Open > Syntax...** แล้วเลือกไฟล์ `start-data.spss` (หรือสร้างหน้าต่าง Syntax ใหม่แล้ววางโค้ดลงไป)
2. **เลือกคำสั่งทั้งหมด:** คลิกที่เมนูบาร์ด้านบนเลือก **Edit > Select All** *(แนะนำให้ใช้เมนูนี้แทน `Ctrl + A` เพื่อป้องกันปัญหาคีย์ลัดไม่ทำงานขณะแป้นพิมพ์เป็นภาษาไทย)*
3. **สั่งรันโปรแกรม:** คลิกเมนู **Run > All**
4. **แสดงผลป้ายกำกับข้อมูล:** สลับไปที่หน้าต่าง **Data View** แล้วกดปุ่มไอคอน **`1 <-> A` (Value Labels)** บนแถบเครื่องมือด้านบน เพื่อเปลี่ยนตัวเลขรหัสให้แสดงเป็นข้อความ (`male`, `Night`, `A`, `B`...)
