## 🗂️ โครงสร้างชุดข้อมูลที่ใช้ในโปรเจกต์

โปรเจกต์นี้แบ่งชุดข้อมูลออกเป็น **2 กลุ่มหลัก** ตามโจทย์ปฏิบัติการ:

### 1. ชุดข้อมูลหลัก 40 แถว (`data1.sav` / `start-data.spss`)
ใช้สำหรับฝึกคำสั่งแปลงค่าตัวแปร (Lab 2) และการกรอง/สรุปผลข้อมูล (Lab 3: Work 3.3 – 3.4) ประกอบด้วยตัวแปรตั้งต้น 6 ตัว:
* `gender`: เพศ (`1 = male`, `2 = female`)
* `age`: อายุ (ปี)
* `status`: ภาคเรียน (`0 = Normal`, `1 = Night`)
* `gradePrg1`: เกรดวิชา Programming 1 (`0 = F` ถึง `4 = A`)
* `gradePrg2`: เกรดวิชา Programming 2 (`0 = F` ถึง `4 = A`)
* `GPA`: เกรดเฉลี่ยสะสม

### 2. ชุดข้อมูลแบบประเมินโครงการ 10 แถว (`practice4_1.sav`)
สร้างขึ้นใหม่สำหรับทำ **Work 4.1** และ **Work 3.2** เก็บข้อมูลระดับความพึงพอใจ 7 ข้อคำถาม (`Data_1_D` ถึง `Data_6_D`) กำหนดรหัส `1 = น้อยที่สุด` ถึง `5 = มากที่สุด`

## 🚀 วิธีใช้งาน SPSS Syntax เบื้องต้น

1. **ตั้งค่าภาษาไทย (Unicode):**
   * ไปที่เมนู **Edit > Options...** > แท็บ **General**
   * หัวข้อ *Character Encoding for Data and Syntax* เลือก **Unicode (universal character set)** แล้วกด **OK**
2. **เปิดหน้าต่างเขียนคำสั่ง:**
   * ไปที่เมนู **File > New > Syntax** แล้ววางโค้ดที่ต้องการ
3. **การรันคำสั่งเพื่อดูผลลัพธ์:**
   * **รันทั้งหมด:** กดเมนู **Run > All**
   * **รันทีละข้อ (สำหรับแคปภาพส่งงาน):** ใช้เมาส์ลากคลุมดำ (Highlight) เฉพาะบล็อกคำสั่งของข้อนั้น แล้วกดไอคอนสามเหลี่ยมสีเขียว (**Run Selection**) หรือกด `Ctrl + R`
4. **การสลับโหมดแสดงผลตาราง (ตัวเลข ↔ ป้ายกำกับ):**
   * คลิกปุ่มไอคอน **`1 <-> A`** บนแถบเครื่องมือในหน้าต่าง Data Editor เพื่อสลับการแสดงผลระหว่างรหัสตัวเลข (`1, 2`) และข้อความ (`male, female` / `มาก, น้อย`)

## 📌 ความคืบหน้าของแล็บ (Roadmap)

### ✅ บทที่ 3 ปฏิบัติ (ส่วนที่ 1): เมนู Transform (`Lab02.sav`)
* [x] **ตัวอย่าง 3.13 – 3.18:** `Compute Variable`, `Recode into Same/Different Variables`, `Automatic Recode`, `Count Values`, `Rank Cases`
* [x] **แบบฝึกหัด 2 (ข้อ 1 – 3):**
  * สร้างตัวแปร `level` แบ่งกลุ่มเกรด `gradePrg1` (`A, B = 1` และ `C, D, F = 0`)
  * สร้างตัวแปร `age1` จัดลำดับอายุจากมากไปน้อย (`Automatic Recode` แบบ Descending)
  * คำนวณตัวแปร `up_age` (`age * 0.10`)
  * สร้างตัวแปร `RGPA` จัดอันดับเกรดเฉลี่ยแยกตามเพศ (`Rank Cases` โดยให้ค่ามากสุดเป็นอันดับ 1)

### ✅ บทที่ 3 ปฏิบัติ (ส่วนที่ 2): เมนู Data & การจัดการแฟ้มข้อมูล
* [x] **Work 3.1 + Work 3.2 (`practice4_1.sav`):** สร้างตัวแปรและป้อนข้อมูลแบบประเมิน 10 ชุด พร้อมสุ่มเลือกตัวอย่าง 50% ด้วย `Select Cases` (`filter_$`)
* [x] **Work 3.3 (`data1.sav`):** กรองข้อมูลตามเงื่อนไข (`Select Cases`) 4 รูปแบบ:
  1. เพศหญิง และอายุเท่ากับ 18 ปี (`gender = 2 & age = 18`)
  2. อายุระหว่าง 20 – 24 ปี (`age >= 20 & age <= 24`)
  3. เพศชาย หรือมีอายุมากกว่า 24 ปี (`gender = 1 | age > 24`)
  4. เลือกลำดับแถวที่ 10 ถึง 20 (`RANGE($CASENUM, 10, 20)`)
* [x] **Work 3.4 (`data1.sav`):** ใช้คำสั่ง `Data > Aggregate` สร้างตัวแปรใหม่ `SD_Age` (ส่วนเบี่ยงเบนมาตรฐานของอายุ) และ `Max_GPA` (ค่าสูงสุดของ GPA) แยกตามเพศ
